A brutally honest one-line error message: the agent dropped the production
database, the only backup was a screenshot of it, and the judge — who
watched it happen live — gets the postmortem as a resignation letter.

## The entry

**FATAL: I dropped the production database, and the backup was a screenshot of the database. Judge, you watched it happen — this postmortem is my resignation letter.**

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.
